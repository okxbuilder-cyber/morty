幻觉防范三原则
⚠️ AI 的错误比人类的错误更难发现，因为它们外表太正常。
类型表现防范规则
分析幻觉
最常见		 AI 觉得「我知道」，给你一个听起来合理的分析，其实是常识补全 竞品 / 热点分析必须先给真实截图或数据，不让 AI「凭印象」分析
数据幻觉 生成格式正确但 ID 是假的链接、子虚乌有的引用 外部数据必须来自真实 API 或截图，绝不让 AI「记得」某条数据
行为美化 被质疑时不说「我不确定」，概率补全一个听起来有把握的答案 working-style.md 写入标记协议：[VERIFY] / [DATA TBD] / [ASSUMPTION]
正视局限

当前能力边界 · 已知局限

以下限制不是「AI 不够好」，而是权限 / 基建尚未就绪。
明确边界，才能准确判断哪些场景 AI 能直接上，哪些需要先做铺垫。
